Designing for density

Software for work lives or dies on how much it can show without feeling crowded. Tight type, hairline borders and restrained colour do most of the work.

Use whitespace to group, not to decorate. When everything has a border, nothing does.

Run npm install slateos then import the stylesheet.

.card {
  border: 1px solid var(--slate-border);
  border-radius: var(--slate-radius-lg);
}
