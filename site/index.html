An open design system for the web.

Neutral, minimal, accessible. Design tokens, plain-CSS components, and light and dark themes. Free to download and use.

Get started See components

Colors

Semantic tokens. Components use these names, so switching theme changes nothing in your markup. Every text pair is checked for WCAG AA contrast at build time.

Typography

Inter for interface text and JetBrains Mono for code, both open-licensed (OFL) and self-hosted.

Quiet, readable interfaces

The quick brown fox jumps over the lazy dog. Body text is 16px with a 1.55 line height.

Small supporting text uses the muted color. --slate-font-size-sm

Use it

Drop the stylesheet in, then use the classes. No build step or framework required.

<link rel="stylesheet" href="https://slateos.ajinkya.design/dist/slateos.css">

<button class="slate-button">Save</button>

Dark mode follows the system by default. Force a theme with <html data-theme="dark"> or "light".
