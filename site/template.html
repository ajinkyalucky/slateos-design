Get started

One stylesheet. No build step.

1 · Add the files

index.html
<link rel="stylesheet" href="https://slateos.ajinkya.design/dist/slateos.css">
<script src="https://slateos.ajinkya.design/dist/slateos.js" defer></script>
<script src="https://slateos.ajinkya.design/dist/icons.js" defer></script>

2 · Use the classes

<button class="slate-button">Save</button>
<button class="slate-button slate-button--secondary">Cancel</button>

3 · Theme it

Dark mode follows the system. Force a theme, or override any token, with plain CSS.

<html data-theme="dark">

:root { --slate-accent-solid: #0f9d8a; }
